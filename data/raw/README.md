# Raw data

Download the dataset ZIP from https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success and extract `data.csv` into this directory.

The source CSV uses semicolons as delimiters. Keep this downloaded copy unchanged. Data files here are excluded from Git.

Source dataset: Realinho et al. (2021), https://doi.org/10.24432/C5MC89. Licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.
